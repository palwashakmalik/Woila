# Contributing to Woila

Use Node 24 or newer. Fork the repository, create a branch, and run `npm ci` followed by `npm test`.

Open an issue for a proposed language rule before changing syntax. Keep sentences deterministic and English-based. Add behavior tests for both the compiler and interpreter when changing syntax or semantics. Include real HTTP requests for backend changes. Document user-facing changes and current limits.

Submit a pull request describing the concrete behavior, examples, and verification. Existing tests must pass. Do not commit credentials, generated release archives, or unrelated changes. Contributions are provided under this project's MIT license.
