# Woila roadmap

## First public release

- Structured English compiler and Node CLI.
- Project starter and GitHub installation.
- Offline browser editor and unpacked Chrome extension.
- Schema validation, in-memory model CRUD and local HTTP endpoints.
- Automated compiler/interpreter, CLI, worker and HTTP tests.
- Local MCP adapter for Claude Desktop/Code: references, checking and compilation.

## Next

- Verify installation and editor behavior on Windows, macOS and Linux.
- Run graphical extension checks in a browser-capable CI runner.
- Publish a scoped npm package after verifying account ownership and package contents.
- Host the playground and publish the extension on the Chrome Web Store.
- Add static cross-file signatures, optional-value narrowing and source maps.
- Design durable model adapters, transactions and migration semantics.

This is an experimental language implementation. Database persistence and production application security are not supplied by the in-memory example backend.
